add_box Add mã TP — Import Excel

Thêm mã thành phẩm trực tiếp vào FG Inventory. Chỉ import dòng nhà máy {{ selectedFactory }}. Import cả ASM1 và ASM2 theo cột Nhà máy.

Cấu trúc file Excel (dòng 1 = tiêu đề, dữ liệu từ dòng 2):

  • Cột A — Nhà máy: ASM1 hoặc ASM2
  • Cột B — Mã TP: mã thành phẩm đầy đủ
  • Cột C — LOT
  • Cột D — LSX
  • Cột E — PO: có thể để trống
  • Cột F — Lượng: số lượng tồn (số nguyên > 0)
  • Cột G — Vị trí: vị trí kho (để trống → Temporary)

Batch tự sinh dạng ADDMA1-000001 / ADDMA2-000001. Dòng trùng (Nhà máy + Mã TP + LOT + LSX + Lượng + Vị trí) sẽ bỏ qua.
