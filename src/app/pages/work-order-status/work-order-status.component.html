add_circle Bổ Sung {{ isBsImport ? '✅ Dữ liệu sẽ lưu vào danh sách Xuất BS — không hiện trên bảng Work Order' : 'Tắt: import thông thường vào PXK' }}

Bấm nút xanh phía trên để mở cửa sổ chọn file trên máy — không cần cuộn xuống dưới.

info Nguồn dữ liệu file

  • File Excel (.xlsx / .xls) được xuất từ hệ thống kho / kế toán (báo cáo phiếu xuất kho — PXK), không phải tự tạo tay trừ khi đúng cấu trúc báo cáo.
  • Chỉ import các dòng có Mã Ctừ = PX (hoặc tương đương chứng từ xuất). Cột Số lệnh sản xuất (LSX) phải đúng định dạng theo nhà máy: ASM1 KZLSX + 4 số + / + 4 số; ASM2 LHLSX + 4 số + / + 4 số.
  • Sau khi import, dữ liệu lưu trên hệ thống để đối chiếu Work Order (So sánh, In PXK). Hệ thống tìm dòng tiêu đề theo tên cột; nếu khớp, thứ tự cột có thể khác form mẫu.
